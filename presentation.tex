\section{Introduction}

\begin{frame}{Motivation}
\begin{itemize}
  \item Earnings-related disclosures update expectations about future cash flows and should affect valuation.
  \item The key issue is not whether a noisy long-window drift exists, but whether a cleaner design identifies defensible short-run pricing adjustment.
  \item Tushare Pro allows us to move from a weak internal proxy to a stronger event-expectation framework.
\end{itemize}
\end{frame}

\begin{frame}{Research Question}
\begin{block}{Core Question}
Do China A-share earnings-related events generate short-run abnormal return once surprise is measured relative to stricter sell-side expectations, and is Tushare-only expectation data strong enough for a credible main headline?
\end{block}
\begin{itemize}
  \item Old version: guidance-only proxy design.
  \item New version: Tushare-first framework with explicit event types and pre-event expectation matching.
  \item Final framing now emphasizes diagnosis of the weak headline result, not a forced positive finding.
\end{itemize}
\end{frame}

\begin{frame}{Diagnostic Result in One Slide}
\begin{itemize}
  \item Headline Tushare-first specification: \texttt{CAR5} on \texttt{main\_surprise\_std}
  \item Current test-run coefficient: \(-0.0030\), p-value: \(0.4967\)
  \item Filtered Tushare-first panel: 4314 rows; usable strict standardized-signal rows: 583
  \item Strongest surviving subset: \texttt{latest\_per\_analyst + preannouncement\_only + raw + CAR10}
  \item That subset has only 101 regression observations and p-value \(0.181\), so it is suggestive, not decisive
\end{itemize}
\end{frame}

\begin{frame}{Ranked Failure Diagnosis}
\begin{itemize}
  \item Coverage collapse: usable strict signal rows are a small share of the full event universe
  \item Thin analyst coverage: many matched events rely on very few broker inputs
  \item Event heterogeneity: pooling preannouncements, revisions, express, and formal releases weakens identification
  \item Benchmark mismatch: \texttt{report\_rc} does not always map cleanly into realized event values
  \item Filtering and standardization choices matter, but they do not rescue the main headline
\end{itemize}
\end{frame}

\begin{frame}{Recommendation}
\begin{block}{Recommendation B}
Keep Tushare as the baseline framework, but add stronger external analyst-expectation data later if the goal is a credible main empirical headline.
\end{block}
\begin{itemize}
  \item Tushare-first still provides a cleaner and more auditable architecture than the old proxy design.
  \item But the current Tushare-only evidence is too weak for a strong headline claim.
  \item The best surviving subset is narrow and still not conventionally significant.
\end{itemize}
\end{frame}

\begin{frame}{What Still Survives}
\begin{itemize}
  \item The cleanest subset is \texttt{preannouncement\_only}, not the pooled all-event sample.
  \item The cleaner benchmark is \texttt{latest\_per\_analyst}, not the thinner latest-snapshot construction.
  \item Raw surprise performs better than the current pooled standardized headline in the surviving subset.
  \item The project therefore shifts from "claiming a result" to "showing what a credible next design should look like".
\end{itemize}
\end{frame}

\begin{frame}{Updated Final Takeaway}
\begin{block}{Recommended headline}
A Tushare-first framework is the right baseline architecture for this project, but the current Tushare-only matched sample is too thin for a strong main conclusion; the credible next step is to keep Tushare as the event framework and add better external analyst-expectation data.
\end{block}
\end{frame}

\begin{frame}{Conclusion}
\begin{itemize}
  \item We successfully replaced the weak guidance-only proxy with a cleaner Tushare-first architecture.
  \item The headline pooled specification does not survive the diagnostic run.
  \item The strongest surviving subset is narrow, preannouncement-focused, and only suggestive.
  \item The final project recommendation is B, not a forced positive headline.
\end{itemize}
\end{frame}

\begin{frame}{Next Step}
\begin{itemize}
  \item Keep the Tushare-first event architecture and audit outputs.
  \item Treat the current results as a diagnostic baseline rather than a final claim.
  \item Add stronger external analyst-expectation data if the project aims to support a main valuation-adjustment headline.
\end{itemize}
\end{frame}
