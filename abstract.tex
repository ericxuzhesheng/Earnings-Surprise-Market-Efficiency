\noindent\textbf{Project Title.} Earnings Surprise, Firm Valuation, and Market Efficiency: Evidence from China.

\noindent\textbf{Background and Motivation.} Earnings-related disclosures matter because they update investor beliefs about future profitability and firm value. The initial version of this project relied on a guidance-only proxy for expected earnings, which was useful for exploration but weak as a headline research design. The revised version therefore rebuilds the project around a Tushare-first framework that combines sell-side expectation data, management preannouncements, earnings express releases, formal financial indicators, and market-control variables in one auditable pipeline.

\noindent\textbf{Research Question.} The core question is whether earnings-related public disclosures in China A-shares generate short-run abnormal return once surprise is measured relative to stricter pre-event sell-side expectations, and whether Tushare-only expectation data are strong enough to support a credible main headline. More broadly, the project now asks which parts of the Tushare-first design survive disciplined diagnostic testing and which limitations likely require stronger external expectation data.

\noindent\textbf{Relevance to FIN803 Corporate Finance.} The topic is closely aligned with the FIN803 syllabus. It relates to \textbf{stock valuation} because earnings disclosures update expected cash flows and therefore intrinsic value. It relates to \textbf{capital markets and information processing} because abnormal return around disclosure events reflects how quickly public information enters prices. It also uses ideas from \textbf{CAPM and expected return benchmarking} because abnormal return is measured relative to market return and the regressions control for firm characteristics and exposure proxies. The final framing remains cautious, valuation-centered, and diagnostic rather than strategy-centered.

\noindent\textbf{Methodology.} The revised framework uses Tushare Pro as the primary data source. Sell-side expectations are drawn from \texttt{report\_rc}. Event types are standardized from \texttt{forecast}/\texttt{forecast\_vip}, \texttt{express}/\texttt{express\_vip}, and \texttt{fina\_indicator}. Market controls are taken from \texttt{daily\_basic}. Surprise is constructed relative to pre-event sell-side expectations and evaluated across multiple benchmark constructions, event subsets, signal definitions, analyst-coverage thresholds, and filter profiles. The main outcome remains short-window abnormal return, especially \(CAR5\), with additional windows \(CAR3\), \(CAR10\), \(CAR20\), and \(CAR60\). The regression design includes industry fixed effects, year-quarter fixed effects, event-type fixed effects, firm-level controls, and firm-clustered standard errors.

\noindent\textbf{Main Finding and Contribution.} The main contribution of the current revision is now both architectural and diagnostic. The repository supports a much stronger and more auditable earnings-surprise framework than the earlier weak-proxy design, and it also produces ranked failure analysis, ablation comparisons, and a strongest-surviving-spec output. The pooled Tushare-first headline specification does not survive the current test run: the strict matched-sample coverage is thin, the main \(CAR5\) standardized-surprise regression is not significant, and the strongest surviving subset is only suggestive rather than decisive. The project recommendation is therefore to keep Tushare as the baseline framework but add stronger external analyst-expectation data later if the goal is a credible main empirical headline.

\noindent\textbf{Current Diagnostic Recommendation.} Recommendation B is the most defensible conclusion: preserve the Tushare-first event architecture and auditability, but do not force a strong Tushare-only headline from a weak matched sample. This is a more credible academic contribution than overstating evidence from either the old proxy design or the current thin matched sample.
